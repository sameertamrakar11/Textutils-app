TextUtils - Word & Character Counter, Extra Space Remover
📌 Overview
TextUtils is a simple yet powerful web app built with JavaScript and React that helps users analyze and manipulate text efficiently.

✨ Features
✅ Word Counter – Instantly count the number of words in your text.
✅ Character Counter – Get the total character count including spaces.
✅ Remove Extra Spaces – Clean up unnecessary spaces for better formatting.
✅ Lightweight & Fast – Built with React for smooth performance.
